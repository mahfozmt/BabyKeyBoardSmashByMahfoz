Scott Hanselman-এর বিখ্যাত [BabySmash](https://github.com/shanselman/babysmash)-কে অনুপ্রেরণা নিয়ে আমরা সম্পূর্ণ নতুন ধারায় এই অ্যাপটি তৈরি করেছি। এটি ছোট বাচ্চাদের জন্য ডিজাইন করা একটি বাংলা কীবোর্ড-গেম, যেখানে তারা সহজে বর্ণ, সংখ্যা ও শব্দ শেখতে পারে—দুই হাতে, একদম মজা করে।

- **বাংলা বর্ণ ও সংখ্যা**: প্রতিটি বোতাম চাপলে বড়, রঙিন বাংলা বর্ণ বা সংখ্যা স্ক্রিনে ভেসে উঠবে।
- **মানানসই ইমোজি ও শব্দ**: প্রতিটি বর্ণের সঙ্গে সংশ্লিষ্ট বড়, স্পষ্ট ইমোজি ও শব্দ দেওয়া আছে।
- **মিষ্টি বাংলা কণ্ঠ**: অক্ষরের সঙ্গে সংশ্লিষ্ট শব্দের সঠিক উচ্চারণ শুনতে পারবেন।
- **আকর্ষণীয় আকৃতি ও মজার শব্দ**: স্পেস, এন্টার, ব্যাকস্পেস ইত্যাদি বিশেষ কী চাপলে রঙিন স্টার, নক্ষত্র, ও মজার শব্দ তুলে ধরা হয়।
- **শিশু-নিরাপদ নিরাপত্তা**: ফুলস্ক্রিন মোডে চলার কারণে উইন্ডোজ কী (Win Key), Alt+Tab, Ctrl+Esc, Sticky Keys এবং অন্যান্য সিস্টেম ফাংশন বন্ধ থাকে।
- **ইন্টারেক্টিভ ক্লিক**: মাউস বা টাচের মাধ্যমে যেকোনো বর্ণে ক্লিক করলেই সেটি সক্রিয় হয়।

## 📥 ইনস্টলেশন নির্দেশিকা

### পদ্ধতি ১: ওয়ান-ক্লিক ইনস্টলার — সাধারণ ব্যবহারকারীদের জন্য

কোনো প্রোগ্রামিং বা জটিল কনফিগারেশন ছাড়াই, আপনি চাইলে সফটওয়্যারটি ঠিক তেমনি ইন্সটল করতে পারবেন, যেমন অন্য সাধারণ প্রোগ্রাম ইন্সটল করেন।

1. **ডাউনলোড করুন**:
   - ওপরে থাকা সবুজ **[📥 Download BabyKeyBoardSmash_Setup.exe](https://github.com/mahfozmt/BabyKeyBoardSmashByMahfoz/releases/latest/download/BabyKeyBoardSmash_Setup.exe)** বাটনে ক্লিক করুন।
2. **সেটআপ চালু করুন**:
   - `BabyKeyBoardSmash_Setup.exe` ফাইলটিতে ডাবল-ক্লিক করুন।
   - একটি সুন্দর ডার্ক-থিমের বাংলা ইন্সটলার উইন্ডো খুলবে।
3. **ইনস্টল বাটনে ক্লিক করুন**:
   - **"ইনস্টল করুন (Install)"** বাটনে ক্লিক করুন।
   - *অ্যাডমিনিস্ট্রেটর পারমিশন বা UAC পাসওয়ার্ড লাগবে না* — এটি সরাসরি ইনস্টল হবে।
4. **শর্টকাট ও লঞ্চ**:
   - ইনস্টলেশন শেষে স্বয়ংক্রিয়ভাবে **Desktop** ও **Start Menu**-তে `BabyKeyBoardSmash` শর্টকাট তৈরি হবে।
   - ইন্সটলার থেকেই **"চালু করুন (Launch)"** বাটনে ক্লিক করে গেমটি শুরু করতে পারবেন।

### পদ্ধতি ২: পোর্টেবল ভার্সন — ইন্সটল ছাড়াই সরাসরি চালানো

আপনি যদি কম্পিউটারে কোনো কিছু ইন্সটল না করতে চান, অথবা পেনড্রাইভ/USB থেকে গেমটি চালাতে চান, তাহলে এই পদ্ধতি ব্যবহার করুন।

1. `dist/app/` ফোল্ডারে যান।
2. `BabyKeyBoardSmash.exe` ফাইলটিতে ডাবল-ক্লিক করুন।
3. কোনো অতিরিক্ত ইন্সটলেশন বা সফটওয়্যার ছাড়াই অ্যাপটি সঙ্গে সঙ্গে চালু হবে।

---

### পদ্ধতি ৩: সোর্স কোড থেকে বিল্ড করা

আপনি চাইলে নিজে কোড পরিবর্তন করতে পারেন, অথবা সোর্স থেকে বিল্ড করে কাস্টমাইজেশনও করতে পারেন।

#### পূর্বশর্ত:
- Windows 10 বা Windows 11
- [.NET 8 SDK](https://dotnet.microsoft.com/download)

#### কমান্ডসমূহ:

```powershell
# ১. রিপোজিটরি ক্লোন করুন
git clone https://github.com/mahfozmt/BabyKeyBoardSmashByMahfoz.git
cd BabyKeyBoardSmashByMahfoz

# ২. ডেভেলপমেন্ট মোডে অ্যাপ রান করুন
dotnet run --project src/BabySmashBN

# ৩. সম্পূর্ণ সলিউশন ও টেস্ট বিল্ড করুন
dotnet build BabyKeyBoardSmashByMahfoz.slnx

# ৪. ইউনিট টেস্ট চালান
dotnet publish tests/BabySmashBN.Tests -c Release -r win-x64 --self-contained -o tests/bin/Release
& "tests/bin/Release/BabySmashBN.Tests.exe"

# ৫. ওয়ান-ক্লিক ইনস্টলার প্যাকেজ তৈরি করুন
./scripts/build_installer.ps1
```

> `./scripts/build_installer.ps1` স্ক্রিপ্টটি স্বয়ংক্রিয়ভাবে মূল গেমটি পাবলিশ করে, অ��যাসেট কম্পাইল করে, এবং একটি ইনস্টলার বানিয়ে দেয়।

## 🗑️ আনইনস্টল নির্দেশিকা

প্রয়োজন শেষে অ্যাপটি সম্পূর্ণ ও পরিষ্কারভাবে মুছে ফেলতে পারেন।

- **পদ্ধতি ক: উইন্ডোজ সেটিংস থেকে**:
  1. উইন্ডোজের **Settings > Apps > Installed apps**-এ যান।
  2. তালিকায় **BabyKeyBoardSmash by Mahfoz** খুঁজুন।
  3. ডান পাশের থ্রি-ডট (`...`) মেনু থেকে **Uninstall** নির্বাচন করুন।
- **পদ্ধতি খ: ফোল্ডার থেকে**:
  - ফোল্ডারে থাকা `Uninstall.exe` ফাইলটিতে ডাবল-ক্লিক করুন।

এর ফলে সমস্ত ফাইল, ডেস্কটপ ও স্টার্ট মেনু শর্টকাট, এবং রেজিস্ট্রি এন্ট্রি মুছে যাবে।
